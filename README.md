# Cargador Universal de Baterias (TP5 - UTN FRP)

Firmware del ESP32 (NodeMCU-32S) del cargador universal de baterias - Tecnologia Electronica, UTN FRP.

Proyecto PlatformIO (VS Code). Aca va solamente el codigo; el hardware (KiCad) y el informe no estan en este repositorio.

## Como descargarlo
- Boton verde **Code -> Download ZIP**, o
- git clone https://github.com/cologit/cargador-universal-baterias.git

Abrir la carpeta con VS Code + PlatformIO y compilar/subir con: pio run -t upload

> Estado: el firmware se sube a este repositorio a medida que se termina.
